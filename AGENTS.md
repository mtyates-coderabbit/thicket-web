# thicket-web

React web storefront for Thicket. Talks to
[thicket-api](https://github.com/mtyates-coderabbit/thicket-api) through Apollo Client.

## Layout

- `src/graphql/` — operations and fragments, one per file. All API access goes through
  these documents; do not write inline `gql` strings.
- `src/gql/graphql.ts` — generated by `npm run codegen`. Never edit by hand.
- `schema/thicket-api.graphql` — vendored API schema, refreshed with `npm run schema:pull`.
- `src/lib/` — helpers that interpret API values (money, order status, payment).
- `src/components/` — UI components.

## Conventions

- After changing any `.graphql` file, run `npm run codegen` and commit the generated output.
- Reuse fragments (`OrderSummary`, `PaymentDetails`) instead of repeating selections.
- API amounts are USD dollars; format them with `formatMoney` only.
- Handle every `OrderStatus` value in `src/lib/orderStatus.ts`.
- Guard nullable fields from generated types before reading them.
- Only depend on API fields that exist on thicket-api `main`.

## Commands

npm run dev
